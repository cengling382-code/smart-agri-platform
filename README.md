# 智慧农业综合管理平台（前端实现）

> 《Web 前端框架技术实训》贯穿项目 · Vue 3 技术栈完整实现
> 覆盖《用户需求（规格）说明书》9 大功能模块与《前端页面清单》全部 69 个页面

## 一、技术栈

| 类别 | 技术 |
|---|---|
| 核心框架 | Vue 3.5（Composition API + `<script setup>`） |
| 构建工具 | Vite 5 |
| 路由 | Vue Router 4（路由级 RBAC 权限守卫） |
| 状态管理 | Pinia（Token / 用户 / 标签页） |
| UI 组件库 | Element Plus（中文语言包 + 主题定制） |
| 图表 | ECharts 5（管理端浅色 / 大屏深色两套主题） |
| HTTP | Axios（自定义 adapter 模拟 REST API，模拟延迟 90-250ms） |
| 二维码 | qrcode（溯源码生成与下载） |

## 六、设计说明

- **色彩体系**：生态绿 `#16A34A`（自然/生长）× 科技蓝 `#2563EB`（数据/可靠），语义色（成功/警告/危险/信息）齐全，大屏独立深海军蓝体系。
- **布局**：经典「左侧菜单 + 顶部导航 + 主内容区」后台布局；最小支持 1280px，栅格自适应降级。
- **动效**：路由过渡（淡入上浮）、卡片交错入场（stagger）、数字滚动（rAF CountUp）、设备呼吸灯、大屏扫描线、雷达波纹；全部动效尊重 `prefers-reduced-motion`。
- **无障碍**：跳转主内容链接（skip-link）、`:focus-visible` 焦点环、图标按钮 aria-label、图表 role=img 描述、语义化标题、4.5:1 对比度。

## 七、Mock 数据说明

所有接口由 `src/mock/` 提供（确定性伪随机种子，数据稳定可复现）：
- 登录返回模拟 JWT Token；写操作（增删改/控制/状态流转）直接更新内存数据并可持久化到 localStorage（键 `agri_mock_db`，清除后恢复初始数据）。
- 传感器时序数据由 `genSeries()` 按参数类型生成 24h/48h/7d 曲线。
- 生产环境仅需将 `src/api/request.js` 的 adapter 移除并配置 `baseURL` 指向 Spring Boot 后端即可无缝切换。

## 八、错误隔离与降级机制（全站稳定性保障）

针对「单页面失败导致全站崩溃」问题的四层防护：

| 层级 | 机制 | 文件 |
|---|---|---|
| L1 全局兜底 | `app.config.errorHandler` + `window.onerror` + `unhandledrejection`：任何异常只记录与提示，绝不中断应用 | `src/utils/errorReport.js`（环形日志、5s 去重） |
| L2 页面边界 | `ErrorBoundary`（`onErrorCaptured` 返回 false）：包裹四端 router-view，单页渲染/生命周期/接口异常仅替换当前页区域，侧栏/导航/其他页面照常 | `src/components/ui/ErrorBoundary.vue` |
| L3 路由降级 | `router.onError` + 错误分类：chunk 加载失败→停留当前页（会话内一次硬刷新拉新资源）；首屏失败→静态 `/route-error` 兜底页（重试/刷新/回首页） | `src/utils/routerError.js`、`src/views/error/RouteError.vue`（静态打包，必可达） |
| L4 细粒度加固 | 请求层强制 timeout（超时/网络错误归一化文案）；ECharts init/setOption 全 try-catch（失败降级占位+重试）；35 处页面异步调用补齐 catch | `src/api/request.js`、`ChartCard/ScreenChart` |

降级 UI 包含：**重试加载本页**（重建页面）、**返回首页 / 上一页 / 刷新整站**、错误详情（触发阶段/调用栈/近期错误记录），路由切换自动复位错误状态。

### 稳定性测试（Vitest，`npm test`）

```bash
npm test    # 15 个用例全部通过
```

覆盖以下异常场景（均验证不会导致全站崩溃）：
1. **页面组件渲染报错**：边界捕获并展示降级 UI、异常不向外传播、边界外兄弟内容不受影响、重试后恢复、切页自动复位
2. **接口请求超时 / 网络错误**：真实超时控制 + 友好文案 + ProTable 降级空态（分页仍可交互）
3. **页面资源 404**：catch-all 命中 NotFound，导航可正常恢复到其他页面
4. **动态加载脚本（chunk）失败**：错误分类与降级决策（停留当前页/硬刷新/静态兜底页）单测覆盖
